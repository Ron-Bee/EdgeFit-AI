## Audience and purpose

This is the illustrated technical guide to the complete EdgeFit AI project,
written for hackathon judges, developers, technical reviewers, and Android /
on-device AI researchers — including readers who do not have an Android device.

It reads like a premium strategy guide combined with a technical reference
manual: every implemented major feature is explained with authentic
screenshots, source-grounded diagrams, and honest evidence-status labels.

## Evidence-status explanation

Every claim in the walkthrough carries one of these honest classifications:

- **IMPLEMENTED** — built in source.
- **PHYSICALLY VERIFIED** — observed on a real device.
- **HOST PASS** — verified by host/CI qualification.
- **PROPOSED** — designed but not yet built.
- **DEPLOYED, honestly empty** — live infrastructure with no published data yet.

A successful Global Evidence submission receipt is **not** equivalent to
qualified or published evidence. Public aggregates require the documented
exact-cohort quorum (5 eligible runs from 3 independent installations) and
Publication Approval B, which remains OFF in v1.1.
