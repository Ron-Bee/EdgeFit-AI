## Publication rules

1. Capture original browser screenshots, not fabricated dashboard populated states.
2. Redact keys, bearer tokens, full device serials, private URLs, or session IDs where sensitive; preserve screenshots with clear documentation of any redaction.
3. Record page URL, capture date, deployed version, and observed result count.
4. Never state `SUBMITTED` is `PUBLISHED`; publication requires independent qualification and quorum.
5. Place verified images in the paths above and link them from `README.md` only after the files exist on the target branch.
6. A dashboard with zero published records is still useful as a truthful deployment screenshot.
