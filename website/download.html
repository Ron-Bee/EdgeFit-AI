What you will need

  • A physical arm64-v8a Android phone (Android 8.0 / API 26+).
  • A GGUF model file you provide yourself — the app never downloads models, and setup instructions ship with the release notes.
  • Optional: your own Meta API key (BYOK) for predictions and agent proposals. Benchmarking works fully offline without one.

  1. Download the APK from the verified GitHub Release above.
  2. Confirm the published SHA-256 checksum matches your file.
  3. Allow install from your browser when Android asks (one-time).
  4. Open EdgeFit AI, stage a GGUF file, and run your first benchmark.
