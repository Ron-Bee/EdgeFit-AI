The Android workflow

  1. 1Select a GGUF model file on the phone.
  2. 2Configure inference: context, threads, prompt.
  3. 3Run a physical benchmark; results stay on-device.
  4. 4Review measured throughput per session.
  5. 5Optionally contribute with explicit consent (in development; staging backend under test, not publicly queryable).

Meta Muse Spark, honestly scoped

EdgeFit uses Meta's Muse Spark model to help analyze validated evidence: a validated tool request runs one fixed read-only query over local SQLite, and the model reasons over the returned rows. No live model outputs are shown on this site, and nothing here implies endorsement by Meta.

Global evidence, gated by proof

The long-term goal is a global network where only verified, consented, comparable phone measurements count. Today: zero verified global aggregates published. The evidence status page tracks exactly what exists and what publication requires.

Provenance honesty

All EdgeFit AI source in this repository is new work started October 26, 2026, for this hackathon. Honey LLM and BeeBench are pre-existing independent projects; EdgeFit does not reuse their code or present their results as its own.
