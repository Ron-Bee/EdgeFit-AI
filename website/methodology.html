Methodology

Physical measurement first

Every candidate measurement starts as a real benchmark run on a real phone: tokens generated, milliseconds elapsed, device class, runtime, and workload recorded together. Self-reported files that cannot prove physical execution are never admitted to the qualified population.

Exact cohorts, never pooled averages

A cohort is the set of runs sharing the exact model hash, device class, runtime, backend, quantization, workload, prompt hash, context length, thread count, token count, sampler, optimization, and build provenance. Runs that differ in any of these are never averaged together. Averages across incompatible runs are the defect this design exists to prevent.

Quorum before publication

A cohort publishes statistics only when it holds at least 5 eligible runs from at least 3 independent installations. Below that, the cohort is listed as insufficient evidence: counts visible, statistics withheld — never zeros, never partial means.

Consent and withdrawal

Contribution requires explicit per-submission consent after previewing the exact shared fields. Consent can be withdrawn at any time; withdrawal is terminal. Revoked evidence is tombstoned and excluded from every statistical surface. Consent policy content is still under review, so no real consent version is approved yet.

Synthetic data stays synthetic

The staging backend runs on synthetic test fixtures. Synthetic rows are marked as test-only, can never satisfy genuine quorum, and are excluded from every public aggregate. No synthetic measurement is ever presented as device evidence.
