# EdgeFit AI — Proposed Commercial Licensing Transition

Status: **DRAFT FOR OWNER / LEGAL REVIEW. NOT A LICENSE CHANGE.**

## Intent

Preserve the publicly released 2026 hackathon snapshot and its MIT permissions, while planning proprietary licensing for original work first released in subsequent commercial versions.

## Non-retroactivity

Versions or portions already distributed under the MIT License remain available under that license; this proposed policy does not revoke previously granted rights. Do not rewrite Git history to conceal those releases.

## Rights and dependencies

Before switching licenses, audit copyright ownership, third-party dependencies (including llama.cpp and model assets), contributions, bundled notices, and hackathon/submission obligations. Retain applicable notices and licenses. A public GitHub repository is still viewable and forkable under GitHub's terms even if future original content is proprietary.

## Proposed release structure

- Preserve the official submitted snapshot by immutable Git commit/tag and archived release documentation.
- Keep existing MIT-licensed code and historical license evidence intact.
- Develop genuinely new original proprietary functionality in a private commercial repository or separately identified modules.
- Use a commercial EULA for compiled applications/services, and separate agreements for consulting clients and enterprise offerings.
- Have qualified counsel review any rights transition before publication.
